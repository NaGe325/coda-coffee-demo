# Coda Coffee Demo

A lightweight, single-file front-end demo for **Coda Coffee — Bean Journey**.

This repository contains a standalone HTML experience that presents a mobile-style coffee journey interface with custom styling and interactive UI behavior.

## Project Structure

- `coda` - Main HTML document (includes markup, styles, and scripts)
- `README.md` - Project documentation

## Features

- Single-file implementation for quick prototyping
- Mobile-first visual layout
- Custom color palette and themed UI components
- Self-contained setup with no external build tooling required

## Getting Started

### Option 1: Open Directly

1. Clone the repository.
2. Open the `coda` file in your browser.

### Option 2: Serve Locally (Recommended)

Use a local static server to avoid browser restrictions and mimic production behavior.

With Python:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/coda
```

## Development Notes

- No package manager or dependency installation is required.
- Edits can be made directly in the `coda` file.
- Keep the file self-contained unless you intentionally split assets into separate files.
